# Apartment Floor Plan Activity

A simple black-and-white interactive classroom activity.

## Files
- `index.html` — webpage
- `style.css` — design
- `script.js` — answer choices and automatic scoring

## Run locally
Open `index.html` in any modern browser.

## Put it online
The easiest free option is GitHub Pages:
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's Settings → Pages.
4. Select the main branch and the root folder.
5. GitHub will give you a shareable `https://...github.io/...` link.

## Answer key
